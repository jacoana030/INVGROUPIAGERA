# INVGROUPIAGERA

Grupo GERA de agentes de IA para investigación económica aplicada, en homenaje al grupo de investigación de la Universidad del Valle. Gestor del proyecto: Jacobo.

Primer proyecto: impacto de la migración en la economía de Cali y el Valle del Cauca.

## Cómo empezar

1. Abrir `INVGROUPIAGERA.Rproj` en RStudio y correr `R/00_paquetes.R` una vez.
2. Abrir el repositorio con Claude Code y pedirle a James que inicie el proyecto activo.

Reglas del grupo, agentes y estructura: ver `CLAUDE.md`.
